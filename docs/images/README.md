### Recommended Screenshot Formatting:
- **Resolution:** 1920x1080 or cropped window at 100% DPI scale.
- **TIA Portal:** Enable "Glasses" icon (Online Monitoring Mode) with green rung indicators showing active power flow for maximum visual impact.
- **Format:** PNG with standard compression.
