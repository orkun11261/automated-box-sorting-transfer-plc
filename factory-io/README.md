# Factory I/O Scene Files

Place your saved Factory I/O 3D simulation scene file in this folder:

- **Filename:** `Counter Uygulama-2.factoryio` (or `box_sorting.factoryio`)
- **Recommended Version:** Factory I/O v2.5.0 or later

### Scene Highlights:
- Dual outfeed sorting line with roller pop-up transfer unit.
- Height detection photo-eye mounted on upstream conveyor stanchion.
- Operator station with Start, Stop, Emergency Stop, and 3-color warning tower.

When committing to GitHub, ensure this scene file is copied into this folder.
